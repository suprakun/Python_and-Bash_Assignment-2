# Python & Bash Assignment 2

This project contains the four Python tasks completed for the TuteDude Python & Bash assignment.

## Tasks

1. `01_grade_checker.py` - Grade Checker
2. `02_student_grades.py` - Student Grades using a dictionary
3. `03_write_file.py` - Write content to a text file
4. `04_read_file.py` - Read content from a text file

## Additional Files

- `assignment_notes.txt` - Text file created by the write-file program
- `Python_Bash_Assignment_2_Documentation.docx` - Assignment documentation
- `screenshot_task_1.png` - Grade Checker execution
- `screenshot_task_2.png` - Student Grades execution
- `screenshot_task_3.png` - Write to File execution
- `screenshot_task_4.png` - Read from File execution

## How to Run

Open a terminal in this folder and run:

```bash
python 01_grade_checker.py
python 02_student_grades.py
python 03_write_file.py
python 04_read_file.py
```
